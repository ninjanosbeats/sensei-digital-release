# SENSEI — NINJANOSBEATS

Site estático do Digital Release SENSEI.

## Publicação com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**; salve.
4. Aguarde a publicação. O endereço esperado será https://ninjanosbeats.github.io/sensei-digital-release/

## Arquivos opcionais
Adicione à raiz:
- `sensei.mp3`
- `sensei.wav`
- `sensei-instrumental.mp3`

Adicione a capa em `assets/sensei-cover.png` (ou .jpg, .jpeg, .webp).

Os botões de áudio e capa são ativados automaticamente quando os arquivos estão presentes. Os áudios não foram incluídos neste repositório porque não estavam disponíveis no material recebido.
